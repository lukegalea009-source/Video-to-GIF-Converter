## Video-to-GIF Converter

# Description

Video-to-GIF Converter is a desktop application based in Python capable of converting video files into the GIF format.\
This is achieved by implementing:\
FFprobe for video metadata extraction, FFmpeg for conversion and PyQt6 for GUI functionality.

# Technologies

**Language:** Python\
**GUI:** PyQt6\
**External tools:** FFmpeg, FFprobe\
**Version control:** Git

# Planned Features

- Video-to-GIF conversion
- FrameRate selector
- GIF width selector
